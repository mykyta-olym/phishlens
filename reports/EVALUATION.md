## Protocol

The model was fitted on PhreshPhish `train` rows dated 2024-07-02 to
2025-09-08. The held-out test uses PhreshPhish `test` rows dated
2025-09-08 to 2025-12-16, which the model never saw. The headline
test also removes every row whose registered domain occurs anywhere in the training split.

Design decisions used validation rows from the training period only. The audit below
looked at class rates over all rows before features were written, so the choice of
excluded fields is not blind to the test split, but no test score informed it. Thresholds
were chosen on validation domains.

The test split was scored on an earlier model before this one. The harmless-edit check in that run exposed a parsing bug: hosts such as `www30.example.com` lost part of their subdomain, so adding `www.` changed the features. The bug was fixed and the model retrained with unchanged settings. The fix came from an equality test, not from a score, and no feature or setting was chosen because of test results. It also moved the seeded validation split, so the threshold moved from 0.42 to 0.435. That means this test split is no longer strictly unseen by the author, and the table below shows what changed.

## Checks
